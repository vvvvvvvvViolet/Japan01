# ฝึกเขียนตัวอักษร (Character Writing Practice)

เว็บแอปฝึกเขียนตัวอักษรแบบสุ่มทีละ 1 ตัว รองรับ **ฮิรางานะ (ญี่ปุ่น)**, **ภาษาจีนพื้นฐาน**, และ **ภาษาอังกฤษพื้นฐาน** เขียนด้วยนิ้ว ปากกา (stylus) หรือเมาส์ แล้วให้แอปตรวจความถูกต้องหลังเขียนเสร็จ เพื่อช่วยทบทวนความจำ

เป็น static site (HTML/CSS/JavaScript ล้วน ไม่ต้อง build) เปิดใช้งานได้ทันที

## วิธีใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ หรือรันเซิร์ฟเวอร์ static ง่าย ๆ เช่น

```bash
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

## ฟีเจอร์

- **โหมดเด็ก (Kids Mode)** — เปิดเป็นค่าเริ่มต้น ออกแบบมาสำหรับเด็กประถม:
  - ตัวอักษร/ปุ่มขนาดใหญ่ขึ้น ให้กำลังใจด้วย **ดาว 1-3 ดวง** แทนเปอร์เซ็นต์ดิบ พร้อมข้อความให้กำลังใจ (ไม่มีคำว่า "ผิด") และเสียงประกอบ (สังเคราะห์ด้วย Web Audio API ไม่ต้องใช้ไฟล์เสียง)
  - **โหมดลอกเงา (trace mode)** — แสดงเงาจางของตัวอักษรเป้าหมายบนกระดาษตั้งแต่ต้นรอบ ให้เด็กลากตามได้ทันที
  - ซ่อนตัวเลือกขั้นสูง (คำศัพท์ HSK5 / TOEIC 600) ออกจากหน้าตั้งค่าโดยอัตโนมัติ และอ่านออกเสียงคำถามให้ฟังทุกครั้งที่เปลี่ยนตัวอักษรใหม่
  - ปิดโหมดเด็กได้ในหน้าตั้งค่า (⚙️) สำหรับผู้ใหญ่/นักเรียนโต จะกลับไปแสดงเปอร์เซ็นต์ความแม่นยำและตัวเลือกขั้นสูงตามปกติ
- **ปุ่ม "👀 ดูวิธีเขียน"** — เล่นแอนิเมชันลำดับขีด (stroke order) ทีละขีดพร้อมเลขกำกับ ให้ดูก่อนเขียนเอง ครอบคลุม **ฮิรางานะพื้นฐาน 46 ตัว และตัวอักษรอังกฤษ A-Z/a-z** (ยังไม่มีข้อมูลสำหรับภาษาจีน/เสียงกล้ำ/เสียงควบ ปุ่มจะซ่อนอัตโนมัติ) ข้อมูลลำดับขีดเป็นเส้นทางแบบย่อที่วาดขึ้นจากความรู้เรื่องลำดับ/ทิศทางขีดมาตรฐาน เน้นจำนวนขีดและทิศทางถูกต้องเป็นหลัก ไม่ใช่รูปแบบอักษรวิจิตรที่ประณีต
- สลับภาษาได้ 3 แบบผ่านหน้าตั้งค่า (⚙️) แต่ละภาษาแบ่งเป็นกลุ่มย่อยที่เปิด/ปิดได้อิสระ:
  - **ฮิรางานะ** — สุ่มตัวอักษร แสดงคำอ่านโรมาจิให้เขียนตอบ (พื้นฐาน, เสียงกล้ำ, เสียงครึ่งกล้ำ, เสียงควบ)
  - **ภาษาจีนพื้นฐาน** — สุ่มตัวเลข 1-10, อักษรพื้นฐาน (人 大 小 …), คำศัพท์พื้นฐาน 2 ตัวอักษร หรือ **คำศัพท์ระดับ HSK5** (~90 คำ เช่น 经济 环境 竞争 挑战) แสดงพินอินให้เขียนตัวอักษรจีนตอบ
  - **ภาษาอังกฤษพื้นฐาน** — ฝึกจับคู่ตัวพิมพ์ใหญ่-เล็ก A-Z (เห็นตัวเล็กให้เขียนตัวใหญ่ หรือกลับกัน) หรือ **คำศัพท์ TOEIC ~600** (~80 คำศัพท์ธุรกิจ/สำนักงานที่พบบ่อย เช่น invoice, schedule, negotiate) แสดงคำแปลภาษาไทยให้เขียนคำศัพท์ภาษาอังกฤษตอบ
  - หมายเหตุ: ชุดคำศัพท์ HSK5 และ TOEIC 600 เป็นคำที่คัดสรรมาเองโดยเน้นความถูกต้อง (พินอิน/การสะกด) ไม่ใช่รายการทางการฉบับเต็มของ HSK หรือ ETS
- วาดตัวอักษรได้ด้วยนิ้ว ปากกา หรือเมาส์ ผ่าน Pointer Events บนแคนวาสที่มีเส้นไกด์ (grid guide)
- ปุ่มย้อนกลับ (undo ทีละสโตรก) และล้างกระดาน
- ตรวจคำตอบด้วยการเทียบพิกเซลลายเส้นที่เขียนกับตัวอักษรอ้างอิง (เรนเดอร์จากฟอนต์ระบบตามภาษาที่เลือก) คำนวณคะแนนความครอบคลุม (coverage) และความแม่นยำ (precision) แล้วแสดงภาพซ้อนทับตัวอักษรที่ถูกต้องให้เปรียบเทียบทันที
- ฟังเสียงอ่าน/ตัวอักษรปัจจุบันได้ (Web Speech API ปรับภาษาให้ตรงกับโหมดที่เลือก)
- เก็บสถิติจำนวนครั้ง ความแม่นยำ และสถิติถูกติดต่อกัน ผ่าน localStorage
- สุ่มแบบถ่วงน้ำหนัก: ตัวอักษรที่เคยเขียนผิดจะถูกสุ่มมาให้ฝึกซ้ำบ่อยขึ้น (แนวทาง spaced repetition อย่างง่าย)
- ตั้งค่ากลุ่มตัวอักษรที่ต้องการฝึกในแต่ละภาษา, ขนาดปากกา, และเปิด/ปิดเส้นไกด์

## โครงสร้างไฟล์

- `index.html` — โครงหน้าเว็บ
- `style.css` — สไตล์
- `kana-data.js` — ข้อมูลตัวอักษรฮิรางานะทั้งหมด
- `chinese-data.js` — ข้อมูลตัวอักษรจีน (ตัวเลข, อักษรพื้นฐาน, คำศัพท์, คำศัพท์ระดับ HSK5)
- `english-data.js` — ข้อมูลตัวอักษร/คำศัพท์ภาษาอังกฤษ (A-Z ตัวพิมพ์ใหญ่/เล็ก, คำศัพท์ TOEIC ~600)
- `stroke-data.js` — ข้อมูลลำดับขีด (โครงเส้นย่อ) สำหรับฮิรางานะพื้นฐาน 46 ตัว และ A-Z/a-z
- `app.js` — ตรรกะแอป (สลับภาษา, โหมดเด็ก, วาดภาพ, ตรวจคำตอบ, แอนิเมชันลำดับขีด, สถิติ, ตั้งค่า)
