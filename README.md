# ฝึกเขียนฮิรางานะ (Hiragana Writing Practice)

เว็บแอปฝึกเขียนตัวอักษรฮิรางานะแบบสุ่มทีละ 1 ตัว เขียนด้วยนิ้ว ปากกา (stylus) หรือเมาส์ แล้วให้แอปตรวจความถูกต้องหลังเขียนเสร็จ เพื่อช่วยทบทวนความจำ

เป็น static site (HTML/CSS/JavaScript ล้วน ไม่ต้อง build) เปิดใช้งานได้ทันที

## วิธีใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ หรือรันเซิร์ฟเวอร์ static ง่าย ๆ เช่น

```bash
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

## ฟีเจอร์

- สุ่มตัวอักษรฮิรางานะทีละ 1 ตัว (แสดงคำอ่านโรมาจิให้เขียนตอบ) พร้อมปุ่มฟังเสียงอ่าน
- วาดตัวอักษรได้ด้วยนิ้ว ปากกา หรือเมาส์ ผ่าน Pointer Events บนแคนวาสที่มีเส้นไกด์ (grid guide)
- ปุ่มย้อนกลับ (undo ทีละสโตรก) และล้างกระดาน
- ตรวจคำตอบด้วยการเทียบพิกเซลลายเส้นที่เขียนกับตัวอักษรอ้างอิง (เรนเดอร์จากฟอนต์ระบบ) คำนวณคะแนนความครอบคลุม (coverage) และความแม่นยำ (precision) แล้วแสดงภาพซ้อนทับตัวอักษรที่ถูกต้องให้เปรียบเทียบทันที
- เก็บสถิติจำนวนครั้ง ความแม่นยำ และสถิติถูกติดต่อกัน ผ่าน localStorage
- สุ่มแบบถ่วงน้ำหนัก: ตัวอักษรที่เคยเขียนผิดจะถูกสุ่มมาให้ฝึกซ้ำบ่อยขึ้น (แนวทาง spaced repetition อย่างง่าย)
- ตั้งค่ากลุ่มตัวอักษรที่ต้องการฝึก (พื้นฐาน, เสียงกล้ำ, เสียงครึ่งกล้ำ, เสียงควบ), ขนาดปากกา, และเปิด/ปิดเส้นไกด์

## โครงสร้างไฟล์

- `index.html` — โครงหน้าเว็บ
- `style.css` — สไตล์
- `kana-data.js` — ข้อมูลตัวอักษรฮิรางานะทั้งหมด
- `app.js` — ตรรกะแอป (วาดภาพ, ตรวจคำตอบ, สถิติ, ตั้งค่า)
